How it works

WikiGPT is a dynamic RAG (Retrieval-Augmented Generation) chatbot. When you ask a question:

  1. It searches Wikipedia for the top matching articles.
  2. It embeds the articles dynamically into a local vector database.
  3. It finds the most relevant segments.
  4. Google Gemini synthesizes the final response with precise citations.
